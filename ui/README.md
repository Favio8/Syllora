# Syllora 独立前端 UI

沿用现有 Syllora 的白色、浅灰侧栏与克莱因蓝（#002FA7），提供三栏学习工作台。此目录是独立 Next.js + React + TypeScript 工程，不引用原仓库源码，不需要业务后端、宿主注入或桌面桥。

## 启动

需要 Node.js 22.19 或更新版本。

```powershell
cd ui
npm ci
npm run dev
```

浏览器打开 http://127.0.0.1:3001。

Windows 可双击本目录的 **start-ui.cmd**，或为它创建桌面快捷方式。脚本会安装缺少的依赖、启动后台开发服务，等待页面可用后打开默认浏览器。服务已运行时直接打开页面。后台日志位于 `.launcher/`。启动逻辑保存在 `scripts/start-ui.ps1`，不依赖业务后端。

本目录独立使用 npm 锁文件，位于现有 pnpm 工作区之外。根目录 `pnpm build:web` 与 `pnpm serve` 继续用于原前端；预览本 UI 请进入本目录执行上述命令。

```powershell
npm run typecheck
npm run build
npm run preview
```

`build` 生成 `out/` 静态前端；`preview` 在 3001 端口预览该产物。开发服务与静态预览使用同一端口，启动其中一个即可。

## 第一版功能

- 主页：初次进入与刷新默认显示主页；左上角应用图标返回主页。包含继续学习、待完成活动、课程进度，以及对话 / 阅读入口。
- 学习统计：近 12 周热力图、7 / 14 / 30 天趋势和学习天数；可以关闭演示记录，只查看本地操作记录。活动时长采用建议时长，非实际计时。
- 图标导航：默认只显示图标，悬停或键盘聚焦时在右侧显示名称。
- 工作台两种学习模式：对话学习、针对资料的辅助阅读。
- 辅助阅读：资料选择、正文显示、划词浮层、AI解释 / AI搜索演示；阅读助手可收起并原位展开，收起时保留结果。
- 我的课程：支持搜索、切换、新建、重命名、归档、恢复与删除。归档保留全部资料和记录，删除需要确认。
- 工作台课程菜单：顶部课程名称旁提供更换课程、课程归档、重命名；切换课程保留当前学习模式。
- 新建课程：填写名称后必须选择图标，提供数学、统计、编程、化学等 12 种图标；实时预览，保存后同步显示在侧栏与课程卡片。旧数据自动匹配默认图标。
- 学习活动：标记完成、本地单选练习、答案解释。
- 学习对话：提问、预设提示、模拟回复、等待状态；输入框下方提供独立练习和添加资料入口。
- 资料库：按课程筛选、搜索、添加资料、移除资料；TXT / Markdown 正文可本地保存与阅读。
- 用户菜单：用户资料、设置、帮助、退出登录；帮助子菜单包含用户指南、协议说明。
- 固定尺寸设置：桌面 860 × 620，左侧用户偏好 / 模型配置 / 显示与交互 / 数据管理，右侧内容滚动；小屏保持分类列并适配宽度。
- 界面外观：显示与交互中提供浅色、深色预览卡片，点击“保存外观”后应用并记住选择；覆盖工作台、主页、图表和浮层菜单。已移除紧凑显示和动画开关。
- 模型配置：接口地址、模型名称、接口格式、随机度和 API 密钥；支持格式检查与本地保存，尚未进行真实 API 调用。
- 统一下拉菜单：圆角浮层、选项间距、展开 / 收起动画、键盘选择、Escape 与外部点击关闭。
- 固定顶部学习模式入口；右侧任务看板支持桌面收起展开和手机抽屉。模式按钮旁不再显示重复控制；收起的右侧栏只保留展开按钮。
- 手机 / 平板布局：抽屉导航、可展开学习面板。
- 浏览器本地保存；弹窗支持 Escape 与焦点约束。
- 文本输入框使用系统箭头指针，点击落点与可见尖端对应；标签、搜索图标和框外留白不会代替输入框获得焦点，支持 Tab 切换。
- 轻量转场：页面与学习模式切换、面板标签、弹窗、菜单、划词工具栏、阅读结果、消息和按钮反馈；支持系统“减少动态效果”设置。

当前聊天和阅读解释由本地规则生成演示回复；AI搜索查找当前资料的相关段落，未连接互联网或模型。TXT / Markdown（最大 1 MB）正文保存在浏览器本地；PDF（最大 20 MB）只保存文件信息，正文解析待后续接入。内置课程的示例 PDF 使用演示文字。旧版保存的资料没有正文时，可以重新添加文本文件。

API 配置中的地址、模型等非密钥字段保存在本地工作空间；密钥仅保存于当前标签页的 `sessionStorage`，不写入 `localStorage`，关闭标签页或恢复演示数据后清除。“检查配置格式”仅做本地校验，真实模型调用仍待接入后端。

用户菜单的“退出登录”返回本地预览的进入页面，退出状态保存在当前标签页会话中，不清除学习数据；真实账号认证尚未接入。知识点证据状态是示例数据，完成活动不会自动提升知识点状态。新建课程初始为空，需要接入后端后才能生成真实大纲与计划。

## 文件结构

```text
app/                     Next.js 页面、全局样式、图标
app/appearance.css       深浅色主题与设置外观预览
src/components/          界面组件与弹窗
src/lib/courseIcons.ts   课程图标选项与旧数据兼容
src/lib/activity.ts      学习日期、统计与明确标记的演示历史
src/hooks/useWorkspace.ts 数据加载、更新与错误处理
src/types/index.ts       前端数据结构与服务契约
src/mocks/workspace.ts   初始演示数据
src/mocks/reading.ts     演示资料正文
src/services/mock.ts     本地模拟服务
src/services/reading.ts  阅读正文、解释与检索演示服务
src/services/index.ts    服务适配器入口
docs/backend-integration.md 后端对接说明
docs/change-report.md    本次修改、验证与交付边界
scripts/preview.mjs      静态产物预览服务
```

后续接接口时实现 `WorkspaceService` 和 `ReadingService`，然后替换 `src/services/index.ts` 的导出。组件不直接请求后端。

界面字体使用系统中文字体与 DM Sans；Google Fonts 不可用时自动使用本地系统字体，功能不受影响。

## 浏览器验证

已包含四套浏览器验证脚本。需要 Python 与 Playwright；保持 UI 服务运行，再执行：

```powershell
python -m pip install playwright
python -m playwright install chromium
python -X utf8 scripts/verify_ui.py
python -X utf8 scripts/verify_revision.py
python -X utf8 scripts/verify_appearance.py
python -X utf8 scripts/verify_input_boundaries.py
```

脚本优先使用 `CHROME_PATH`；Windows 已安装标准路径的 Chrome 时直接使用，否则使用 Playwright Chromium。可用 `UI_URL` 指定其他预览地址。脚本使用隔离浏览器环境，检查主页与导航、课程图标选择及持久保存、转场与减少动态效果、响应式布局、用户菜单、真实鼠标划词、文本导入及原有课程与聊天功能。截图保存到 `docs/preview*.png`。

新增验证覆盖输入框下方操作、任务与阅读助手收起、模式按钮位置、统计记录、归档恢复、删除确认、设置固定尺寸、API 配置校验与会话密钥、圆角菜单键盘操作及移动端布局。

外观验证覆盖主题保存与取消、刷新持久化、旧偏好兼容、深色卡片与文字对比度、浮层菜单主题、顶部课程操作、简化收起栏及手机展开入口。

输入验证检查 11 个输入框的四侧框外点击、框内激活、箭头指针、键盘切换，以及深色学习时间底色、保存和手机单位布局。
