# 输入框聚焦边框调整报告

日期：2026-10-02，第四轮 UI 调整。

## 修改内容

- 所有文本输入框、数字输入框、日期框、下拉选择框和多行文本框，聚焦时直接在原边缘内侧加粗，去掉分离的外圈和间隔。
- 搜索框、对话输入区、带单位输入框只强调最外层边缘，内部输入控件不再重复显示一圈边框。
- 按钮和图标选项的键盘焦点保留，焦点边框间距统一为零。
- 深浅色主题均使用当前主题的强调色，聚焦前后尺寸保持一致。

修改文件：`apps/web/src/features/workbench/integrated.css`。本次没有改变后端接口或课程存储规则，接口说明继续见《前端接口对接说明-2026-10-02.md》。

- 生产构建及桌面资源组装成功，Windows NSIS 安装包生成成功。
