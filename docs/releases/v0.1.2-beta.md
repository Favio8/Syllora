Syllora 0.1.2-beta 将新版工作台接入正式 Web 与 Electron 应用。两端使用同一份前端源码和静态构建，独立 UI 工程已移除。

本次更新：

- 统一首页、课程目录、图标、主题、导航及响应式阅读界面，所有正式学习流程连接本机 Host。
- 阅读正文、划词解释和课程资料内搜索使用发布版本的真实来源，支持引用定位与 PDF 原件预览。
- 称呼、主题和默认每日分钟数持久化；版本冲突保留输入。课程隔离草稿支持刷新恢复和迟到响应保护。
- 计划、问答、练习判分、证据状态、错题复习、争议与会话继续由后端规则决定；学习统计使用去重的真实活动。
- 修复 CLI npm 包遗漏动态运行时模块的问题。

旧课程、来源版本、计划、作答、证据、供应商配置及加密凭据继续兼容。旧记录缺少的信息显示未知，不补造历史；课程删除保留原始资料。

下载与使用：

- Windows：`Syllora-0.1.2-beta-setup.exe`，自带本机 Host 和新版 Web。
- macOS：按设备选择 arm64 或 x64 的 DMG；ZIP 为同版本桌面产物。
- Linux：AppImage 或 DEB。
- Web：`Syllora-web-0.1.2-beta.zip`，由 Syllora Host 托管；独立安装 CLI 后设置 `SYLLORA_WEB_DIST` 指向展开目录，再运行 `syllora serve`。
- CLI：`syllora-cli-0.1.2-beta.tgz` 可通过 `npm install -g ./syllora-cli-0.1.2-beta.tgz` 安装。本次仅提供 tarball，不发布 npm registry。
