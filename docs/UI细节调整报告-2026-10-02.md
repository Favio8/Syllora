# UI 第二轮细节调整

2026-10-02。工程：`D:\xks\Syllora-main`。根据用户本轮 9 项要求修改；第 10 项为空，未推断额外要求。本报告中的设置和授权规则优先于同日第一轮报告。

## 修改结果

1. 资料库与复习页搜索框仅绘制一层背景和边框；内部输入透明、无独立边框，焦点反馈由外层提供，浅色与深色统一。空列表图标与文字也统一居中。
2. 复习面板“学习过程记录”“生成执行诊断”“复习间隔设置”改成真实按钮，含图标、圆角边框、展开箭头、悬停与选中状态；支持键盘和展开/收起，折叠不丢弃表单草稿。
3. 热力图保持真实 84 天数据，补齐首尾不满一周的占位；占位不生成活动、不参与统计、不可点击。图形为 7 行、等列数，所有格子为正方形。
4. 模型配置的“添加供应商”和“供应商管理”增加可见圆角边框，移除其下分隔横线。
5. 移除“外部调用授权”整块设置，本地应用直接允许调用用户配置的模型。已有的 `consent:false` 文件不会继续阻止生成；兼容旧客户端的 `preferences` 调用会保存启用状态。停止任务、资料删除和过期版本校验继续有效。独立 `SylloraService` 的显式宿主 `isConsented` 回调仍可作为集成约束，本地课程管理器使用启用策略。
6. 删除用户指定的归档管理长说明及旧空状态引导，使用简短“暂无归档”；恢复和永久删除操作保留，删除确认中仍呈现实际影响。
7. 删除诊断日志指定长说明，保留读取、导出及打开日志目录入口。
8. 设置删除“用户偏好”，默认进入模型配置；侧栏只有模型配置、显示与交互、数据管理。称呼和每日学习时间合并进左下角“用户资料”，继续调用 `uiPreferences` 并使用原 `baseVersion` 冲突处理。

## 实现与接口

新增 `apps/web/src/features/workbench/components/ReviewDisclosure.tsx`。修改工作台入口、学习指标、统计、用户资料、偏好编辑器、模型入口与集成样式，以及 Host 的 `syllora.ts` / `syllora-projects.ts`。

未新增业务 API。`uiPreferences` 字段与修订语义保持一致，入口位置变化。授权兼容行为有变化：`state.settings.consent` 对本地应用为 `true`，旧 `preferences({consent:false})` 不再撤销本地授权或取消现有任务；任务取消继续使用 `cancel`。这项变更落实用户“直接改成允许”的要求，没有后台自动发起模型调用。
