## 当前实现

| 领域 | 首版行为 |
| --- | --- |
| 课程 | 新建、切换、重命名、归档恢复、确认删除；使用稳定 ID |
| 资料 | PDF 物理页定位、MD/TXT 段落定位、粘贴正文；内容指纹去重，限额检查，空页部分可用确认 |
| 大纲 | 从模型结构化输出生成章节／知识点，校验引用归属；用户选择本轮范围 |
| 计划 | 每日分钟、未来天数、休息日；容量不足明确列出；草案确认后激活，旧版本与旧草案拒绝覆盖 |
| 问答 | 复用现有模型适配器，限定课程资料；不足标记，来源可查看；安全 Markdown，无自动外部图片加载 |
| 测验 | 四选一，服务端冻结答案；生成后再次模型复核；选项、引用原文、重复题校验；提交前隐藏答案与解析 |
| 作答 | 固定答案判分，提交幂等，重复题提交返回原记录；提前看答案标记辅助学习 |
| 证据 | 从有效独立作答重放：未评估、待验证、待加强、初步掌握、复测通过 |
| 复习 | 24／72／168 小时间隔，错误回退，提前练习不推进延迟复测；显示下次到期时间 |
| 纠错 | 报错后题版本暂停计入，重新计算证据；原作答保留，原题位可以生成替代题 |
| 持久化 | 单进程串行写入，临时文件原子替换；课程、计划、原始作答同一快照，派生状态可重算 |
| 异步生成 | 持久化作业记录、课程内生成互斥、取消、启动恢复；删除／归档／资料移除时禁止迟到发布 |
| 设置 | 复用 StudyClaw 模型配置与加密凭据存储；独立 Syllora 数据目录，外部调用告知与累计次数上限 |

## 代码入口

- 前端：`apps/web/src/components/Syllora.tsx`、`syllora.css`。
- 接口：原 Node Host 中的 `/api/syllora/*`，沿用本地 token 与 Origin 检查。
- 服务：`packages/host/chat-service/src/syllora.ts`。
- 规则：`packages/host/chat-service/src/syllora-domain.ts`。
- PDF：复用 `packages/course/builder/src/extract.ts` 中的 PDFParse，增加保留物理页码的提取入口。
- 模型：复用 `adapter.ts`、`config.ts`、`settings.ts`、`secret-box.ts`；没有新增自主 Agent 执行工具。

- 费用金额没有虚构默认值。当前限制累计模型调用次数，金额费用显示未知；供应商价格、完整用量计价和会话／演示金额预算仍待接入。

- 资料保存提取后的来源片段；文本型 PDF 另存原文件并支持预览（见下文「A 包补强记录」），MD/TXT 与粘贴正文不保留原文件。部分可用检测列出失败页码与原因（空白页／解析未返回），但仍无法保证表格、公式或扫描页识别完整。
- 模型上下文限制为约 22,000 字符，按知识点来源／问题匹配选择片段；超出部分不能声称已阅读，实际使用范围与未覆盖资料会在界面显式告知（见「A 包补强记录」）。大纲完整覆盖和大型中文检索需要后续加强。
- 题目提供结构校验、逐字依据核对和模型复核，仍需人工验证唯一答案。只拦截规范化完全重复，语义近重复识别尚未完成。
- 数据采用单进程 JSON 原子快照；不支持多个 Host 同时写同一数据目录。删除当前快照不会清理用户自行创建的备份或外部模型服务留存。
- 全量 PRD 验收、真实内容抽检与性能测量留待下一轮；当前交付不等同于发布签核。

## A 包（资料与引用）补强记录

日期：2026-10-01。基于 `main`（`7ca6466`）实现，范围仅限 PRD FR-02／FR-04 中「资料与引用」工作包标记为未完成的四项，不改动其他工作包，不新增依赖。

| 项 | PRD 依据 | 实现 |
| --- | --- | --- |
| 原资料预览 | 6.3「用户可预览原资料与解析正文」、AC-02 | 文本型 PDF 原文件保留到 `.syllora-data/files/<id>.pdf`（0600）；新增 `materialFile` 动作与 `GET /api/syllora/material-file` 路由，经 token 门禁与课程／资料归属校验后回原字节（`application/pdf`、`nosniff`、`inline`）；课程视图输出 `previewUrl`，资料面板提供「预览原文件」。删除资料或整门课程时同步删除原文件 |
| 失败页明细 | 6.2 partial「列出失败范围」、14.3「指出成功与失败范围」、AC-16 | `Material.pageIssues` 记录逐页原因：`blank-page`（空白页）、`unextracted-text`（解析器未返回该页）、`parse-failed`；解析器抛错时回具体原因而非笼统格式错误；前端以可展开列表列出失败页码，并说明这些页不参与生成 |
| 资料版本 | 6.3「每份资料保存 material_id、version」、6.4、AC-21 | `Material.version`／`versionOf`，旧快照由 `normalizeCourse` 补为 v1。相同内容指纹复用已有版本并提示，不重复拆解；同名但正文不同则建立独立资料线（版本号递增、`versionOf` 指向上一份），旧资料与其来源继续可用——不静默替换，不换掉原节点 |
| 长资料覆盖 | 17.4「说明使用范围，不声称读完全文」、6.1「不在后台截断后冒充全文可用」 | 上下文选择改为两趟：先按相关度排序（所有 kind，不再只有 answer），再为尚未覆盖的资料各保留一个片段，避免长资料挤掉其余资料；`Job.coverage` 记录 `sourcesUsed/sourcesTotal/charsUsed/charsTotal/materialsWithOmitted` 并在界面显示；提示词显式声明未选入片段不参与、不得声称已读全部资料 |

设计取舍：`version` 采用「每份上传都是独立资料线」，不自动取代旧版本。PRD 6.4 只要求「改变正文创建新版本」而未定义触发规则，此处按用户确认的规则实现，AC-21「不换掉原节点」因此自然成立。
