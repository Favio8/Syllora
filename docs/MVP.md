## 当前实现

| 领域 | 首版行为 |
| --- | --- |
| 课程 | 打开本地课程文件夹、最近课程、重命名、归档恢复、确认删除；持久化 UUID，支持搬迁后重新打开；旧课程逐个迁移 |
| 资料 | 检查文件与增量、用户排除、上传／粘贴保存原文；结构分段，PDF 物理页及失败页明细；鉴权原件预览与版本序号，历史来源保留；容量保护与部分可用确认 |
| 大纲与讲义 | 逐章节分批整理全部选中资料，生成导读、解释、资料例子与知识联系；引用逐字校验与来源覆盖检查；用户选择学习范围 |
| 幻灯片讲义（可选） | `ui.slides` 开启后每批额外产出符合 OpenMAIC DSL 契约的结构化幻灯片，可翻页阅读并导出单页 PNG；失败只记录、不影响讲义发布；旧 revision 读作无幻灯片（见 [OPENMAIC_SLIDES.md](OPENMAIC_SLIDES.md)） |
| 计划 | 每日分钟、未来天数、休息日；容量不足明确列出；草案确认后激活，旧版本与旧草案拒绝覆盖 |
| 问答 | 限定已发布课程资料；不足标记与引用；记录实际上下文来源、字符与省略范围，先为各资料预留来源；安全 Markdown |
| 测验 | 四选一，服务端冻结答案；生成后再次模型复核；选项、引用原文、重复题校验；提交前隐藏答案与解析 |
| 作答 | 固定答案判分，提交幂等，重复题提交返回原记录；提前看答案标记辅助学习 |
| 证据 | 从有效独立作答重放：未评估、待验证、待加强、初步掌握、复测通过 |
| 复习 | 24／72／168 小时间隔，错误回退，提前练习不推进延迟复测；显示下次到期时间 |
| 纠错 | 报错后题版本暂停计入，重新计算证据；原作答保留，原题位可以生成替代题 |
| 持久化 | 每课程独立快照，串行原子写入；整理版本先暂存、校验后发布；作答与学习记录保留，派生状态可重算 |
| 异步生成 | 持久化任务、课程内互斥、阶段进度、取消与中断恢复；重试复用未变化资料的检查点，每批自动失败重试至多一次 |
| 设置 | 应用共享模型配置与加密凭据，密钥保留在本机应用数据目录；外部调用授权；2026-10-02 移除累计次数上限 |

## 代码入口

- 前端：`apps/web/src/components/Syllora.tsx`、`syllora.css`。
- 接口：原 Node Host 中的 `/api/syllora/*`，沿用本地 token 与 Origin 检查。
- 服务：`packages/host/chat-service/src/syllora.ts`。
- 课程目录与初始化：`syllora-projects.ts`、`syllora-files.ts`、`syllora-initialize.ts`；存储与接口见 [COURSE_PROJECTS.md](COURSE_PROJECTS.md)。
- 规则：`packages/host/chat-service/src/syllora-domain.ts`。
- PDF：复用 `packages/course/builder/src/extract.ts` 中的 PDFParse，增加保留物理页码的提取入口。
- 模型：复用 `adapter.ts`、`config.ts`、`settings.ts`、`secret-box.ts`；没有新增自主 Agent 执行工具。
