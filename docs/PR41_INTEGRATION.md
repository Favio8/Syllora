## 审查发现与修复

| 问题 | 最终行为 |
| --- | --- |
| 原分支落后于 main，覆盖大纲和计划相关改动 | 正向合并 main 与课程目录实现，保留已有学习功能，无强制推送 |
| Anthropic 模型发现遗漏协议，缓存不区分协议 | 设置与会话目录均传递协议；缓存按协议、地址和密钥摘要隔离 |
| 地址已有 `/v1` 时重复拼接，目录仅返回首批模型 | 接受根地址或版本地址，处理 `after_id` 分页和 `display_name`，异常分页不缓存 |
| 任意网络错误后隐藏重发生成 POST | 适配器不直接重发；调用方拥有重试策略及物理调用记录 |
| 流中断、空文本、无参数工具调用和初始文本的边界不完整 | 中断明确失败，空文本不冒充成功，无 JSON 增量的工具调用可交付，保留初始文本 |
| `Retry-After: 0` 导致错误构造失败；重定向可能转发自定义密钥头 | 保留正确错误分类；不向重定向地址转发凭据 |
| Strict Mode 使 `initial=null` 设置加载结果失效；加载错误被吞掉 | 组件自行加载、卸载后不写状态，失败显示并可重试；保留协议草稿 |
| 自定义目录入口配置一次后消失 | 可继续添加自定义供应商，初始 ID 自动避开已有项 |
| 桌面旧快照只复制 JSON，遗漏管理的 PDF | 先复制原件，再复制快照，保留旧数据和已有目标 |
| 目录打开桥允许打开宿主子树中的文件或链接 | 仅放行已知应用／宿主／日志目录，拒绝文件、其他目录及链接 |
| 切换设置分区时标题与关闭按钮被滚出弹窗 | 限制滚动到内容区，固定标题布局，并在浏览器断言关闭按钮位于弹窗内 |
| 日志先完整读入内存，再截断 | 最多读取七份日志，每份只读最近 256 KiB，并标明截断 |
| 桌面组装只复制入口，遗漏上传模块动态 JS 分片 | 复制 CLI 发布清单中的完整扁平 JS 闭包 |
| Windows 退出探针依赖进程结束请求，可能绕过或无法触达关闭钩子 | 向 Electron 原生窗口发送关闭请求；严格模式检查正常退出与残留进程 |

Anthropic 协议核对依据：[流式事件文档](https://platform.claude.com/docs/en/build-with-claude/streaming)、[模型目录接口](https://platform.claude.com/docs/en/api/models/list)、[参数弃用说明](https://platform.claude.com/docs/en/about-claude/model-deprecations)。Anthropic 使用供应商默认采样，避免将 OpenAI 的默认温度强制传入不接受非默认采样参数的 Claude 模型。

## 验证边界

模型响应来自明确标识的本地测试服务，未调用真实供应商；真实模型讲义的语义质量仍需人工抽检。Anthropic 当前支持文本和普通工具调用，不提供图片输入、可配置扩展思考、需要回传签名思考块的多轮工具调用或服务端工具；不承诺兼容所有第三方网关。Syllora 首页的资料整理、问答和题目使用文本请求。复杂版面和 OCR 仍属于后续阶段。
