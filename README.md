# AI软件赛道 - Syllora - 子非鱼

**Turn every course into a learning system.**

把每一门课程，变成一个会持续进化的学习系统。

Syllora 是基于 StudyClaw 直接复用开发的本机 AI 学习工作台。首版提供课程与资料管理、引用问答、学习计划、单选题练习、证据状态和复习安排。当前交付为 MVP，不代表整份 PRD 的发布验收已经完成。

## 启动

评审公网部署采用 Vercel 静态前端、本机独立 Host 与 ngrok，运行和恢复步骤见 [评审部署说明](docs/REVIEW_DEPLOYMENT.md)。普通本机启动与评审实例的数据相互独立。

使用 Node.js 22.19+（或 24+）与 pnpm 11。

```powershell
pnpm install --frozen-lockfile
pnpm build:web
pnpm serve
```

浏览器打开终端显示的本地地址，默认 `http://127.0.0.1:8080`。

端口被占用时：

```powershell
pnpm serve --port 8081
```

服务默认只监听本机地址，沿用原项目的访问 token 与 Origin 校验。不要将此 MVP 直接暴露到公网。

## 处理效率与实测用时

初始化把资料整理成讲义的链路是**两段式**：① DocMind 解析（PDF/Word/PPT/Excel/HTML/Markdown/TXT）；② 模型按**最外层标题**把解析结果提炼成结构化知识文档（一章一次调用），再按节生成讲义（每批 ≤16k 字符 / ≤6 节，并发 = 设置里的「最大并发」）。

**实测（2026-10-04，桌面版，小米 MiMo v2.6-flash，并发 3）** 以示例课《电路基础 · AI 提炼示例》为对象：

| 阶段 | 调用次数 | 用时 |
| --- | --- | --- |
| DocMind 解析（2.4 万字符的 md → 5.3 万字符 markdown） | — | ≈ 6 秒 |
| 提炼成结构化知识文档（1 个章节块 → 1.68 万字符） | 1 | ≈ 4 分钟 |
| 按节整理讲义（6 个批次，全批发布、零失败） | 6 | ≈ 6 分钟 |
| **端到端合计** | **7** | **≈ 10 分 20 秒**（覆盖率 33/33 节） |

作为对照：**旧口径**（不提炼，直接对 DocMind 的原始碎片按批整理）对同一份材料会产生约 **98 个批次**（每批正文平均仅几十字、元数据占大头），按同样模型预估 **50–65 分钟**。

提速要点与可调项：

- 用时主要取决于**所选模型的速度**与**设置里的「最大并发」**：并发默认 8（上限 16），上表是本机并发 3 的成绩；提高并发或换更快的模型档位会明显更快。
- 提炼结果与讲义批次都有缓存（`parse-v7` / `lecture-v2`，按模型 + 内容指纹），**取消或失败后重跑只补没完成的批次**；换模型会重新提炼。
- 单次模型调用的超时放宽到 10 分钟（旧口径 240 秒会把慢模型的批次掐成 `UPSTREAM_TIMEOUT`）。
- 讲义阶段的失败重试、二分拆批与检查点机制保持不变；「每节必须被引用、引文必须逐字命中原文」的校验不放松。

## 第一次使用

1. 打开左下角「用户 → 设置」，添加供应商，填写模型服务地址、model_id 和 API Key。支持 OpenAI 兼容与 Anthropic Messages 两种协议；已有供应商在「供应商管理」中编辑、激活或删除。
2. 阅读外部调用说明，勾选授权。供应商账户费用与额度由你自行管理；Syllora 不设置累计调用次数上限。每道题包含生成与复核两次调用。
3. 点击「新建课程」，选择图标和已有本地目录。一门课程对应一个文件夹；最近课程可直接切换，重命名只改变显示名称。
4. 在右侧「资料」检查文件、排除不需要的内容，点击「初始化课程」。也可以上传文本 PDF、UTF-8 MD/TXT 或粘贴正文；新增内容先保存到课程的 `sources/`，确认后再整理。
5. 在「讲义」阅读章节导读、概念解释、原文依据与资料例子；在「大纲」选择学习范围、每天分钟数、未来天数和休息日。
6. 生成计划草案，检查容量后点击「确认生效」。
7. 点击「继续」，获取有来源的讲解，确认完成讲解学习，生成并提交练习题。
8. 查看知识点状态和复习时间；有争议的题目可报错，原作答保留，但相关证据暂停计入并重新计算。

模型调用失败、缺少配置或供应商额度不足时，应用保留已经保存的资料与学习记录。不会用预设答案替代真实模型生成。

文本 PDF 初始化后可点击「预览原文件」，通过本地鉴权读取原字节；原件已变化时先提示更新，避免把新原件当作旧讲义的依据。PDF 的失败页列表显示物理页码与原因；资料行显示版本序号。问答和题目任务记录实际使用的候选片段与未使用资料，单次上下文有限时明确提示。

2026-10-02 起，`preferences` 仅要求 `consent`；旧客户端传入的 `callLimit` 会被忽略，旧快照中的该字段读取时移除，并在下次写入时落盘。`state.settings` 返回 `consent` 与诊断用的 `calls`，不再返回 `callLimit` 或 `cost`。未授权仍禁止向外部模型发送资料。

计划可填写目标日期（按课程时区计算，含当天，最多 366 天）和知识点学习估时（5–240 分钟整数，默认 20 分钟）。未填写目标日期时使用未来天数；目标日期已过的草案不能确认。容量提示区分单任务超过每天分钟数和时间窗口放不下。旧计划快照在读取时补充默认字段，并迁移容量提示格式，无需手动修改数据文件。

大纲支持重命名、上移和下移，排程沿用大纲顺序。草案中的每个未开始任务可调整为 1–720 分钟；装不下的任务保留在不可行草案中，降低估时后可重新排程。任务估时调整会更新草案 ID，旧页面的确认或调整请求返回 `VERSION_CONFLICT`。差异窗口保存打开时的计划与草案快照，展示调整前后的日期与估时；确认后才生效。

独立错答会生成包含即时巩固任务的调整草案，保留原计划、休息日、目标日期、估时和学习证据；已有草案时不覆盖。草案仍需用户确认，不会自动替换已生效计划。计划快照新增 `days`；旧快照按已有任务日期跨度补齐，无任务时补为 7 天。`plan` 接口兼容 `targetDate` 作为 `deadline` 的别名，两者同时传入时必须一致；`adjustTaskMinutes` 要求当前 `draftId`、`taskId` 与 `minutes`。

## 目录与复用关系

正式前端已统一为 PR #43 的新版工作台，源码位于 `apps/web`，Electron 使用同一份 `apps/web/out` 静态产物。独立 `ui` 工程已移除；接口、兼容和启动说明见 [统一工作台](docs/UNIFIED_WORKBENCH.md)。

```text
apps/web/                           Next.js / React 前端
apps/cli/                           原 Node Host 与本地访问保护
packages/host/chat-service/src/
  syllora.ts                        Syllora 接口、作业与持久化
  syllora-projects.ts                课程目录、共享设置与旧课程迁移
  syllora-files.ts                   文件扫描、结构分段与来源检索
  syllora-initialize.ts              分批整理、检查点与版本发布
  syllora-domain.ts                 计划、证据、复习规则
packages/course/builder/            复用资料解析与结构化模型调用
packages/llm/                       复用模型适配
vendor/                             保留的上游基础组件与许可
scripts/syllora-serve.mjs           Syllora 启动入口
```

Syllora 使用独立的规则：两道不同题独立正确达到初步掌握，至少经过 24 小时再完成到期复测；复习间隔为 24／72／168 小时。辅助作答不计独立证据，答错后重新补强。

## 本地数据

- `.syllora-home/`：服务注册、访问 token、凭据加密主密钥等。
- `.syllora-data/.syllora/`：应用共享模型配置、加密凭据、外部调用授权和最近课程路径。旧 `.syllora-data/syllora.json` 保留为逐课程迁移来源。
- 每个课程根目录的 `.syllora/course.json`：稳定课程 UUID、学习记录、任务与当前产物版本指针；`.syllora/revisions/<版本>/`：解析正文、来源、大纲与章节 Markdown 讲义。
- 两个目录均已加入 `.gitignore`。迁移配置时需同时保留主密钥和加密凭据，不要公开这些目录。
- 可通过 `SYLLORA_HOME` 和 `SYLLORA_DATA_DIR` 环境变量指定独立目录。不同服务实例不要共享可写数据目录。
- 模型配置由所有课程共享，不向课程目录复制密钥。课程目录中的继承模块文件保留。自有包名为 `@syllora/*`，CLI 命令为 `syllora`；兼容与恢复方法见 [运行目录与命名迁移](docs/RUNTIME_MIGRATION.md)。
- 搬迁时复制的旧 `.studyclaw/`、`courses/`、`artifacts/` 和临时目录不作为 Syllora 默认数据源，也不纳入代码提交。

## 当前边界

支持本机单用户浏览器与 Electron 桌面壳；桌面运行与打包命令见 [桌面说明](apps/desktop/README.md)。上传资料的解析统一走**阿里云 DocMind**（PDF、Word、PPT、Excel、HTML、Markdown、TXT 都会上传到云端解析；每条来源的物理页码/字符区间、失败页列表与引证口径不变）。未配置 DocMind 时本地回退并在资料上明确标注「这份资料没有走 DocMind」。上限随之放宽：单份 ≤150 MiB / ≤400 页 / ≤150 万字符，课程合计 ≤1600 页 / ≤600 万字符——整本教材可以进来，讲义的整理会分批进行（可取消、有检查点）。解析产物（DocMind markdown、章节大纲、本地化图片）随课程版本落盘，阅读页用它提供章节导航、「版式视图」与阅读标记；`state` 轮询只带来源定位信息，正文按需取。

初始化默认走**两段式**：DocMind 解析 → 模型按最外层标题提炼成结构化知识文档 → 按节整理讲义（见上一节的实测数据；`ui: { digest: false }` 可回到旧的逐片段口径）。按项目要求，**AI 工作时不再受「只依据上传资料」的约束**：讲义、对话、笔记、辅助阅读都允许模型结合通用学科知识作答（辅助阅读本就是自由作答）；但**给出引用时仍要求可回溯**——讲义引文必须逐字命中提炼文本或对应的原材料原文，来源标识必须真实存在。资料问答的「本次使用 N 个片段」标注与来源核对保持不变。

扫描 PDF、复杂公式完整识别、多人公开部署、完整 PRD 验收及赛事物料不包含在本轮交付中。费用计价、金额预算与余额管理已按用户决定移出当前范围。

当前首页按课程文件夹保存状态。初始化逐章节处理全部选中正文，每次请求仍有上下文保护；取消、失败或中断保留上一份有效版本。文件变化需重新扫描并由用户更新，不自动激活学习范围或计划。课程资料默认保存在应用所在目录的 `.syllora/<课程 UUID>/`，新建课程只填写名称和图标。原已登记课程首次访问时复制资料与学习记录到新目录，原文件保留；旧汇总课程从首页逐个迁移到自动分配的目录；只有旧片段的资料明确标记缺少原文件。删除课程只清理本应用管理的课程记录与整理产物，保留原文件、课程根目录及继承模块文件。接口与存储契约见 [课程文件夹与初始化](docs/COURSE_PROJECTS.md)。

完整实现记录、验证边界和后续事项见 [docs/MVP.md](docs/MVP.md)。最新逐项需求及人工验收门槛见 [PRD 验收矩阵](docs/PRD_ACCEPTANCE.md)。真实模型和实际课程资料尚待运行时接入。

幻灯片讲义是**可选**能力，且**生成在云端**：在课程 `.syllora/config.yaml` 同时配好 `ui: { slides: true }` 与 `cloud`（云端 OpenMAIC 地址与访问口令）后，初始化会按章节调用云端生成课堂幻灯片，取回后在本地渲染、翻页与导出（PNG / PPTX）。默认关闭，因此既不产生云端请求、也不上传任何资料；**开启意味着本章资料会上传到你所配置的服务器**。连接步骤（地址与口令从哪来、四步顺序、每种连不上分别是什么报错）、产物与边界见 [幻灯片讲义](docs/OPENMAIC_SLIDES.md)；云端各接口的请求与响应契约见 [云端 OpenMAIC 取回产物 API](docs/OPENMAIC_CLOUD_API.md)。
虚拟课堂（顶栏学习模式的第三个入口）复用同一条云端链路：在**设置 → 模型配置 → 虚拟课堂（云端 OpenMAIC）**填服务地址与访问口令（口令加密保存、不回显，也可继续手写 `cloud` 段），未配置时页面只给引导、不发任何请求。发起后按「合并资料 → 上传 → 云端生成 → 轮询 → 取回整份课堂」编排，六步进度与场景计数实时可见、可取消；完成后本地播放幻灯片（`@openmaic/renderer` 画布）、测验（作答与查看答案）与互动演示（沙箱 iframe），讲解台词逐条显示。课堂产物写在课程目录的 `classrooms/<课堂 id>/`（`classroom.json` / `meta.json` / `progress.json`，播放进度只记阅读状态、不计学习证据），生成作业同时出现在左栏「任务」页。**开启意味着所选资料会上传到所配置的服务器**：设置卡片与输入卡片都会明示；云端限制为一次最多 5 份、合计 150 MB、单份 50 MB，因此附件最多再带 4 份。部署、数据流向、本地产物、排障对照与验收清单见 [虚拟课堂部署与运维](docs/OPENMAIC_CLASSROOM.md)。

云端链路本身的**接口契约、每个端点的实测结果、以及生成产物的取回方式**见 [云端 OpenMAIC 取回产物 API](docs/OPENMAIC_CLOUD_API.md)；手写 `cloud` 段时的连接步骤与排障对照见 [幻灯片讲义](docs/OPENMAIC_SLIDES.md)。

未来任务会显示课程时区的可执行时间，不能直接提前开始；调整草案并确认后才改变日期。新增复习在原计划剩余容量内跨日安排，保留休息日、截止日期和已有任务。已有未开始或进行中复习时，新的错答只更新证据，不重复创建任务或空草案。在「复习」中按知识点查看错题、自己的选项、解析与依据；目标日期之外的复习另有提示。

任务来源失效时，保留原任务和作答并提示补充资料。整理新资料后，明确选择支持同一知识点的整理结果并确认关联，再恢复新讲解和练习；旧失效题证据不会恢复。课程删除失败显示「重试删除课程」，重启后仍停止该课程学习读写；重试只清理应用产物，原文件保留。

生成 Job 新增可选的 `promptVersion`、`ruleVersion`、`finishedAt`、`elapsedMs` 与 `errorCode` 诊断。旧 Job 缺少这些字段时保持未知。供应商配额、限流、鉴权、超时、取消和截断输出分别提示；等待超过 60 秒仍查询原 Job，不自动重复生成。问答/单题请求实际中止上限仍为现有 120 秒，课程初始化按批次使用该上限；它与观察超时不同。调用次数和可取得 token 用量继续记录，不恢复应用内费用或累计次数上限。

「复习」现可显式修改未来复习间隔与新会话的闲置时长；历史作答与已有到期不重写。学习会话按点击开始记录，刷新/切课保留，普通时钟和合成验证分开；过程记录显示闭环观察窗、已记录来源展示/报错、调整接受及帮助原因，零分母不显示假完成率。执行诊断标注部分 token 用量完整度。新题复核分批比较全部本知识点历史题的语义近重复；真实模型准确性仍需人工核验。边界与复验脚本见 [学习过程记录](docs/LEARNING_OBSERVATIONS.md)。

同一课程删除资料与初始化/大纲生成/上传互斥，清理期间返回明确忙碌状态；操作历史完整保存，界面仅显示最近 40 条；另一页面修改学习设置时保留本页未保存输入与原修订号，需明确载入最新设置。复验及历史失败见 [PRD 验收矩阵](docs/PRD_ACCEPTANCE.md)。

浏览器联调脚本 `scripts/syllora-e2e.ts` 使用明确标识的本地模型测试服务，不代表真实模型效果；产物写入外层工作区 `tmp/`。

设置分为模型配置、显示与交互、数据管理（归档管理/诊断日志）；称呼与每日目标在左下角用户资料中修改。日志通过鉴权接口读取，最多七份、每份最近 256 KiB，可导出排查。桌面壳共享配置位于 `<userData>/syllora-data/.syllora/`，与课程原始资料分开保存。Anthropic Base URL 可填写 API 根地址或含 `/v1` 的地址；旧配置缺少 `protocol` 时沿用 OpenAI 兼容协议。当前 Anthropic 适配支持文本与工具调用，暂不提供图片输入及可配置扩展思考。
